# Programa 1 - Calculadora de Algebra Lineal

Proyecto universitario para resolver sistemas de ecuaciones lineales por eliminacion por filas.

## Restricciones

No se usa:

- PySide6
- NumPy
- SciPy

El algoritmo de eliminacion por filas esta implementado manualmente.

## Como ejecutar

En Visual Studio Code, abre esta carpeta y ejecuta:

```powershell
python "Programa 1_Grupo3.py"
```

Si Windows no reconoce `python`, usa:

```powershell
py "Programa 1_Grupo3.py"
```

## Como probar

```powershell
python -m unittest test_algoritmo.py
```

Alternativa en Windows:

```powershell
py -m unittest test_algoritmo.py
```

## Framework elegido

Se usa Tkinter porque viene incluido con Python, permite construir una interfaz grafica sencilla y es facil de explicar en la defensa.
